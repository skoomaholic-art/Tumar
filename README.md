# Тумар

Сюжетная игра о Второй мировой войне: казах из степного аула, 1942–1945. Вид из травы или сверху,
диалоги с выбором и таймером, память персонажей, блокнот Асана. Браузерная игра на three.js без сборки.

История и персонажи вымышлены. Сцены написаны по мотивам опубликованных воспоминаний фронтовиков,
бывших военнопленных и остарбайтеров (список — в документе сюжета и в финальных титрах).

## Запуск

Нужен любой локальный сервер (данные глав грузятся через `fetch`, с `file://` не заработает):

```
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Устройство

```
index.html            разметка интерфейса и порядок подключения скриптов
css/style.css         оформление
data/chNN.json        главы: тексты, цели, сценарии диалогов и выборов
js/core/script.js     сценарный движок (шаги say/choose/set/if/remember/diary/word/testify/call…)
js/core/memory.js     память игры: флаги, отношения персонажей, блокнот, показания, загрузка глав
js/core/save.js       сохранения в localStorage с версией формата
js/core/testimony.js  показания и противоречия для допросов главы 8
js/core/*.js          звук, движок, интерфейс, ввод, плёночное зерно
js/scenes/*.js        код сцен: геймплей, камера, крючки, которые зовёт сценарий
js/main.js            порядок глав, финал, главный цикл, титульный экран
tests/                проверки сценарного движка и допросов (node --test)
```

Новая глава пишется так: тексты и ветки — в `data/chNN.json`, геймплей и постановка — в `js/scenes/`,
связь между ними — через `{"call": "имяКрючка"}` в сценарии.

## Проверки

```
npm test
```

## Сохранения

Только локально, в браузере игрока (`tumar-save`). Игра сохраняется в начале и в конце главы,
не посреди сцен. «Новая игра» поверх сохранения срабатывает со второго нажатия.
